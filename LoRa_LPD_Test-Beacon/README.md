# Description
This is the main project directory used for Visual Studio Code. There is also the Platform IO extension ini file here to which was used for building and flashing comands to the LoRa Heltec boards. 

The code is intended to be reusable for all configs of LoRa by modifying only the header for SF and BW and rebuilding and reflashing. 

The primary library used for LoRa control is found below:
https://jgromes.github.io/RadioLib/
